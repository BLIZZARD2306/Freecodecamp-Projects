# freeCodeCamp Responsive Web Design Portfolio

A complete compilation of all the projects and exercises I built while completing the [freeCodeCamp Responsive Web Design](https://www.freecodecamp.org/learn/responsive-web-design/) certification. 

This repository documents my journey of learning web development from the ground up, focusing on semantic HTML, modern CSS (including Flexbox and CSS Grid), and foundational JavaScript. Feel free to browse the folders above to explore the code for all the exercises and final projects!

## 🛠️ Technologies Used
* **HTML5:** Semantic structuring and accessibility.
* **CSS3:** Custom styling, responsive layouts, Flexbox, and Grid.
* **JavaScript:** Basic DOM manipulation and logic.

## 🎓 What I Learned

Through building the numerous projects and exercises in this course, I developed a strong understanding of:
* Mobile-first design principles.
* Absolute and relative positioning.
* How to use CSS variables for consistent theming.
* Designing accessible websites for screen readers.
